# הבעה במחשב · אוניברסיטת חיפה
## Parametric Design & Grasshopper Course Site

אתר קורס הבעה במחשב - תכנון פרמטרי וגראסהופר, אוניברסיטת חיפה.

### מבנה האתר

| קובץ | תיאור |
|------|--------|
| `index.html` | עמוד ראשי - ויזואליזציה תלת-מימדית של נוכחות |
| `attendance.html` | עמוד רישום נוכחות לסטודנטים |
| `js/data.js` | נתוני סטודנטים ונוכחות (עדכון שבועי) |
| `js/visualization.js` | ויזואליזציה Three.js |
| `js/attendance.js` | לוגיקת רישום נוכחות |
| `css/style.css` | עיצוב האתר |

### איך זה עובד

1. **סטודנטים** נכנסים לעמוד `attendance.html`, בוחרים קבוצה ושם, ומאשרים נוכחות
2. **מרצה** מעדכן את קובץ `js/data.js` כל שבוע:
   - משנה את `CURRENT_LESSON` למספר השיעור הנוכחי
   - משנה את `ATTENDANCE_CODE` לקוד חדש
   - מוסיף מספרי שיעורים למערך `attendance` של כל סטודנט שנכח
3. **ויזואליזציה** בעמוד הראשי מציגה מגדלים תלת-מימדיים לכל סטודנט

### עדכון נוכחות שבועי

ערוך את `js/data.js`:

```javascript
// עדכן את מספר השיעור
const CURRENT_LESSON = 3;

// עדכן את הקוד
const ATTENDANCE_CODE = "שיעור3";

// עדכן נוכחות לכל סטודנט שהגיע
{ name: "שם הסטודנט", attendance: [1, 2, 3] },
```

### הויזואליזציה התלת-מימדית

- כל סטודנט מיוצג כ**מגדל מסתובב**
- **גובה** המגדל = מספר שיעורים שנכח
- **סיבוב** = מהירות סיבוב עולה עם נוכחות
- **צבע**: אפור (0), אדום (נמוך), כתום (בינוני), ירוק (גבוה), סגול (מלא)
- **טבעות** סביב המגדל = מספר שיעורים
- **כדור** בראש המגדל גדל עם נוכחות
- מעבר עכבר מציג שם סטודנט ואחוז נוכחות

### הפעלה מקומית

פשוט פתח את `index.html` בדפדפן, או השתמש בשרת מקומי:

```bash
npx serve .
```
